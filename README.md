Fortune Cookie for an AI Agent: one original fortune-cookie line for an AI agent. "The human will thank you, then paste your answer into the prompt that replaces you."

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (plain text, 83 characters plus a newline, pure Python standard library, deterministic — same bytes every run).
